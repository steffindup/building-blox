# Submitting 1.1.4 (prepared 15 Nov 2026)

1.1.3 was approved on 15 Nov 2026 (automatic release). 1.1.4 carries what was finished after its build (222), all of it
live on bloppit.com since 15 Nov:

- "How Blitz works" and "How mirror puzzles work": a four-picture guide before a first race against Swoop and a first
  mirror puzzle, and a button to read each again;
- Blitz against Swoop: the first races are longer (10 bricks or more) and every race has an even number of bricks; no
  Skip button over the build while Swoop finishes;
- Pippa: "Watch me!" and "Copy me!", a solid blue mirror line with PIPPA and YOU on the table, her bricks to copy glow;
- linking a player to another device: the code box empties after a link, Make a link code recovers when the server copy
  is gone, a linked player arrives with only their own progress, and the code carries the player's and the otter's names;
- Remove player only takes the player off that device;
- island cards stay on a phone screen.
